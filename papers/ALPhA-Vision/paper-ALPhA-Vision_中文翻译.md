## ——787μs 人脸检测延迟，低于 5mW 平均功耗

## 摘　要

ALPhA-Vision 是一款面向边缘 SoC 的常开低功耗 DNN 视觉推理子系统。该子系统灵活可编程，同时支持 CNN 与 ViT 推理，并通过软硬件协同设计实现了完全端到端执行，**全程无需访问外部存储器**。借助精细粒度的功耗管理机制抑制漏电流，该子系统可在 60fps 帧率下以 **787μs 延迟**完成人脸检测，检测精度达 **99.3%**，平均功耗仅 **4.6mW**。

---

## 一、引言与设计动机

常开型计算机视觉（CV）任务是用户存在检测、安全监控和手势控制等应用的关键工作负载。随着具身人工智能走向主流，常开视觉（Always-on Vision, AoV）将愈发普及 [1]。在消费设备中，利用人脸检测实现笔记本电脑屏幕智能息屏等用例，若能以低功耗持续运行低延迟视觉流水线，可带来可观的系统级功耗收益。典型的视觉流水线同时包含深度神经网络（DNN）推理和经典 CV 算子，需要一个灵活且功能完备的平台来完成端到端处理。基于 GPU 的边缘 SoC 虽能执行此类负载，但其 ~10W 的功耗使其难以胜任 AoV 场景 [2]。

本文提出 **ALPhA-Vision**（Always-on Low-Power Accelerator for Vision，常开低功耗视觉加速器），可作为专用子系统集成于更大规模的高性能 SoC 中，使得 SoC 其余部分处于休眠时，该独立子系统仍能以低功耗持续运行（见图 31.9.1）。该可编程子系统支持多种 DNN 推理负载，涵盖**卷积神经网络（CNN）** 和**视觉 Transformer（ViT）**；专用硬件不仅加速矩阵乘（GEMM）内核，还覆盖 CV DNN 中常见的众多其他层类型，确保非 GEMM 操作不构成低延迟执行的瓶颈。通过激进量化和容量最大化的硬件实现，图像输入可实现完全本地的端到端处理而无需访问外部存储器。面向精细粒度功耗管理的软硬件协同设计，即使在高帧率下也能将功耗预算控制在 5mW 以下。配套的全栈编译器流程在完成硬件兼容的量化感知训练（QAT）、保持任务精度的前提下，将应用源代码编译为可执行二进制文件。上述组件协同运作，实现在不唤醒整个 SoC 的高功耗 CPU、GPU 或主存系统的条件下，完成 AoV 流水线的端到端执行。

## 二、架构与设计概述

图 31.9.2 展示了 ALPhA-Vision 的架构组成：

| 组件 | 功能 |
|------|------|
| **DLA**（深度学习加速器） | 执行 GEMM 运算 |
| **NMP**（近存储处理器） | 专用于低计算强度内核 |
| **RV**（32 位 RISC-V Rocket）[3] | 系统控制器 |
| **全局存储系统** | 2.125MB SRAM，容纳全部常驻权重和激活值 |

不同于先前采用专用低漏电工艺的超低功耗边缘方案 [4–10]，ALPhA-Vision 定位为大型 SoC 中的子系统，因此仍使用标准高性能工艺。这意味着 SRAM 漏电流在总功耗中占比很高，最小化漏电功耗成为系统设计的**首要约束**。降低静态功耗最关键的手段是让系统**"竞速休眠"（race to sleep）**，即尽可能延长处于低功耗休眠模式的时间。为此，计算单元针对典型负载的亚毫秒级端到端延迟进行了优化，确保即使在 60fps 高帧率场景下，系统每帧的绝大部分时间仍可处于休眠状态。

### A. 深度学习加速器（DLA）

DLA 负责加速构成 DNN 计算主体的卷积和 GEMM 内核。DLA 支持 **INT8** 和带有**微缩放（microscaling）机制的 INT4**（采用 INT8 缩放因子，块大小为 32）[11,12]，在 32 条并行通道上执行矩阵-向量乘法，每条通道每周期完成 32 个元素的向量乘加（INT8 为 16 个），满利用率下总计 **1024 MAC/周期**（INT8 为 512 MAC/周期）。权重和激活值初始存放于全局存储器中，通过本地缓冲、收集器以及地址生成器协同调度，实现**"输出驻留、局部权重驻留"（output-stationary, local-weight-stationary）**的高效数据流，以最大化数据复用 [13]，同时在各类 GEMM 尺寸上保持高利用率。后处理单元（PPU）负责偏置加法、缩放以及简单激活操作（如 ReLU 和 Tanh）。

### B. 近存储处理器（NMP）

仅凭 DLA 的计算加速能力，不足以在端到端 DNN 推理负载上实现低延迟——原因在于大量**低计算强度的"长尾"操作**将占据剩余的大部分运行时间。NMP 是一个可编程向量引擎，以 128B/周期的高带宽接入全局存储器，专门加速这类残余负载：

| NMP 能力 | 详情 |
|---------|------|
| DWConv | 专用引擎，32 MAC/周期 |
| 非 GEMM 操作 | GroupNorm、SoftMax |
| 逐元素操作 | 加、乘等 |
| 存储搬运操作 | Shuffle、Transpose |
| 透视变换 | 专用引擎，卸载经典 CV 算子 |
| 精度 | 全部以 INT8 执行 |

### C. 全局存储系统

全局存储器与加速器协同设计，在避免存储瓶颈的同时最大化容量：

| 存储器 | Bank 数 | 读带宽 | 写带宽 | 存放内容 |
|--------|---------|--------|--------|----------|
| **GWM**（全局权重存储器） | 16 | 68B/周期 | — | 绝大部分权重 |
| **GS**（全局暂存器） | 64 | 136B/周期 | 65B/周期 | 输入图像、中间激活值、DWConv 权重、RV 程序 |

GS 的高 bank 数量支持精细粒度的存储管理，允许对不同 bank 发起多个并行访问。其中 14 个物理 bank 被静态编组为虚拟 bank 簇以获取更高带宽。虚拟到物理地址的转换由加速器地址生成器在运行时以硬件方式完成，并可针对每个 DNN 层进行重配置。全局存储器避免使用大型、昂贵的交叉开关结构，其代价是编译器须强制保证每个 bank 在同一时刻最多被一个请求方独占访问。

## 三、功耗管理技术

ALPhA-Vision 从两个方向降低静态功耗——静态功耗是每帧能耗的主要成分：一是直接优化漏电本身，二是最小化活动模式延迟以延长子系统处于休眠模式的时间（见图 31.9.3）。

### 关键节能特性

**1. 精细粒度 SRAM 休眠状态：**
- GWM 与 GS 中的每个 bank 可被独立置于**保持模式**（retention，仅电源门控外围电路）或**休眠模式**（sleep，电源门控整个宏单元），大幅削减漏电功耗
- 上述设定可在活动模式执行期间实时调整，实现精细粒度的休眠状态动态控制 [14]
- 保持模式：漏电相比活动模式降低约 **3 倍**
- 休眠模式：漏电相比活动模式降低约 **100 倍**

**2. 时钟门控（Clock Gating, CG）：**
- 硬件管理的叶级时钟门控
- 软件控制的 DLA 与 NMP 块级时钟门控
- 软件可编程的**根级时钟门控**：从根部关断整棵时钟分配树，仅保留一个 31 位计数器作为重启时钟的定时器

**3. 高阈值电压（HVT）标准单元**：除时钟树外优先选用，以最小化漏电流

**4. 深度配置存储器**：DLA 与 NMP 内支持多达 **384 个内核融合**后连续背靠背执行，全程无需 RV 干预

**5. RISC-V 双倍时钟执行模式**：RV 时钟以系统其余部分两倍的频率运行，2× 时钟域与 1× 时钟域之间跨域延迟为零周期

## 四、软件流程与编译

图 31.9.4 概述了应用软件流程：

1. **PyTorch** 应用软件 → 逐层量化配置（兼顾硬件约束与精度保持）
2. 执行 **QAT**，产生可在硬件上运行的逐层量化权重、偏置及缩放因子
3. 软件栈在 GWM 和 GS 中分配存储空间，跟踪激活数据的**存活期（liveness）**
4. 利用 **Timeloop** [15] 以高层硬件抽象模型将每个 GEMM 映射到 DLA，选择最优循环嵌套维度
5. 将量化后的各层**融合**为一个或多个执行内核

借助该流程，**Yolov5n-0.5** [16] 的权重和峰值激活存储占用分别压缩至 **318KB** 和 **461KB**，同时保持任务精度不变，由此实现了完全片上执行，无需任何外部存储访问。

## 五、测量结果

ALPhA-Vision 子系统以独立测试芯片形式在 **16nm** 工艺下流片验证，有效面积 **4.20mm²**。本测试芯片在 0.6V 电压下运行于 **359MHz**（RV 718MHz）——这一适中的时钟频率既减少了对 LVT 单元替换和门尺寸放大的需求，又使延迟足够低以支撑"竞速休眠"策略。

### 人脸检测（Yolov5n，WiderFace [19] 训练集，192×192 灰度输入）

| 指标 | 数值 |
|------|------|
| 人脸检测延迟 | **787μs** |
| 峰值吞吐率 | 1270fps |
| 60fps 下每帧休眠占比 | **95.3%** |
| 检测精度 | **99.3%**（WiderFace），95.9%（FDDB [22]） |
| 60fps 平均功耗 | **4.6mW** |
| 底限漏电功耗（时钟停振、全部 SRAM 休眠） | 1.8mW |

### 单帧运行时间分解
- 非 GEMM 操作仅占活动周期的 **21%**——加速器有效消除了计算瓶颈

### 功耗优化技术收益
- 活动能量节省 **21%**（其中 10 个百分点来自将负载拆分为多个内核，以支持更细粒度的 SRAM 休眠状态重配置）
- 休眠能量节省 **94%**

### 跨多种负载的通用性评估（MobileVitv2 [20]、Yolov5、透视变换）
- DLA 平均计算利用率：**81%**
- NMP 平均带宽利用率：**86%**

## 七、结　论

ALPhA-Vision 验证了这样一个命题：一款可编程、灵活的常开视觉子系统，完全能够以 787μs 的亚毫秒级人脸检测延迟实现 99.3% 的精度，同时将平均功耗控制在 4.6mW。

### 五项关键创新

1. **无外部存储访问**的完全片上端到端执行
2. **DLA + NMP 异构计算架构**，全面覆盖 GEMM 与非 GEMM 操作
3. **精细粒度 SRAM 电源门控**，主动削减漏电流
4. **"竞速休眠"策略**，最小化活动模式占空比
5. **全栈编译器流程**与硬件兼容的 QAT

测量结果表明，ALPhA-Vision 子系统能够在功耗严重受限的边缘设备中实现常开视觉应用。相比基于 GPU 的方案（~10W → ~4.6mW），功耗降幅超过三个数量级（**>2000×**）。
